使用说明

GitHub 文件与 API 加速服务 · 基于 Cloudflare Workers

一、加速下载（核心）

  1. 1

    复制任意 GitHub 文件链接

    支持 release 附件、仓库归档 archive、源码文件 raw/blob、gist、api 等链接形态。

  2. 2

    粘贴到首页输入框

    可直接粘贴完整链接，如 github.com/user/repo/releases/download/v1/app.zip。

  3. 3

    点击右侧下载图标

    主按钮为下载箭头图标，点击后自动走 Cloudflare 代理加速，跳转到 ?url=... 地址开始下载。

二、加速下载示例

  • Release 附件 github.com/user/project/releases/download/v1/app.zip
  • raw 文件 raw.githubusercontent.com/user/project/main/file.js
  • 仓库归档 github.com/user/project/archive/refs/heads/main.zip

三、浏览 Release 列表

  1. 1

    点击「Release」开关

    开启后，右侧的下载图标会切换为「获取列表」按钮。

  2. 2

    输入仓库名并点击「获取列表」

    支持 user/repo、github.com/user/repo、完整链接等多种输入形态。

  3. 3

    查看全部 Release

    下方分页渲染该仓库的所有版本，最新一条带「最新」徽标；每个文件都带独立的「下载」与「复制链接」按钮，无附件的版本提供源码包下载。

四、注意事项

  • ! 暂不支持文件夹整体下载，请下载单个文件或仓库归档包。
  • ! Release 列表查询依赖 GitHub 未认证接口，达到限流（约 60 次/小时）时会提示，请稍后再试。
  • i release 附件在列表内可单独点击「复制链接」获取加速后的下载地址，或直接「下载」。
