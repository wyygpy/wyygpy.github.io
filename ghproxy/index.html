GitHub 文件加速

基于 Cloudflare Workers · release / archive / raw / gist / api 全链路加速

✨ 支持带协议头 (https://) 或不带的 GitHub 链接，同时支持 API 加速。
🚀 release、archive 使用 Cloudflare 加速，文件会跳转至 JsDelivr。
⚠️ 注意：暂不支持文件夹下载。
合法输入示例
  • 分支源码 https://github.com/user/project/archive/master.zip
  • release 源码 https://github.com/user/project/archive/v0.1.0.tar.gz
  • release 文件 https://github.com/user/project/releases/download/v0.1.0/example.zip
  • commit 文件 https://github.com/user/project/blob/123/filename
  • gist https://gist.githubusercontent.com/user/123/raw/cmd.py
  • api https://api.github.com/repos/user/project
